Если хоть раз писали чит / перебирали процессы - для вас все станет ясно сразу 

Задается структура размером 0x238 - &entry, arg1 - processId аргумент функции - сверяется с var_240 ( предположительно currProcessId ) 

Переводит процессы (названия) в нижний регистр 

IDA64.EXE       → ida64.exe
X64DBG.EXE      → x64dbg.exe
WINDBG.EXE      → windbg.exe

В sub_140006ea0 *предположительно расшифровываются строки имен запрещенных процессов и затем *точно  эти имена проверяются на совпадения
